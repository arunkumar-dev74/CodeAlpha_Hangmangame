CodeAlpha Hangman Game

About

This is a simple text-based Hangman Game developed using Python as part of the CodeAlpha Internship Task 1.

Game Features

- 5 predefined words
- Player guesses one letter at a time
- Maximum 6 incorrect guesses
- Displays guessed letters
- Shows win or lose message
- Simple console-based interface

Technologies Used

- Python
- Random Module
- While Loop
- If-Else Statements
- Strings
- Lists

How to Play

1. Run the Python program.
2. Guess one letter at a time.
3. Correct guesses reveal the hidden letters.
4. You get a maximum of 6 incorrect guesses.
5. Guess the complete word to win!

How to Run

python hangman.py
